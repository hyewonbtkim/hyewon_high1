## #3 식품개발자가 읽는 '당류 0g · 고단백' 표시의 진실

| 항목 | 내용 |
|---|---|
| 업로드 | 목 10/22 저녁 6시대 |
| 기둥 / 목표 | C 식품개발자의 원재료 읽기 / **저장** |
| 형식 | Carousel 7장 (실제 라벨 예시 이미지 활용) |
| 근거 | 「대체당 총정리」 저장 1,320(3위) · 저장률 1.63% · 팔로우 67. 「배달 식단 브랜드」 저장률 3.14%(전체 1위). 프로필 4-7 우선 기획 3번, "C 기둥을 키울 것" |

**첫 줄 (헤드라인 공식 ⑤ 전문가의 자기 고백)**
```
식품개발자인 저도 처음엔 속았습니다. '당류 0g', '고단백' 표시 이렇게 읽으세요
```

**카드 구성** (기준점은 아래 '식약처 표시기준 확인 결과' 표 참고)
1. 표지: "'당류 0g'인데 왜 달까?" + 라벨 확대 이미지
2. ① **당류 0g ≠ 당이 0** — 0.5g 미만이면 "0", 1g 미만이면 "1g 미만"으로 표시 가능. 단, 총내용량 기준으로 0이 아니면 다른 단위(1회 섭취참고량 등)로도 0 표시 불가 → **'총내용량' 기준 칸을 먼저 보기**
3. ② **무당 vs 저당** — 무당 = 100g(100ml)당 당류 0.5g 미만 / 저당 = 100g당 5g 미만, 100ml당 2.5g 미만. '저당'은 당이 '적은' 거지 없는 게 아님
4. ③ **무가당 ≠ 무당** — 무가당(설탕 무첨가) = 당류·꿀·시럽·올리고당·잼·농축과즙 등을 **넣지 않았다**는 뜻. 우유의 유당, 과일 자체의 당처럼 **원래 있던 당은 남아 있을 수 있음**
5. ④ **'무당' 옆 작은 글씨 찾기** — 무당·무가당 제품에 감미료를 썼다면 바로 옆에 '감미료 함유'(또는 '당알코올 함유')를 14pt 이상으로 써야 함. 저열량이 아니면 '총 열량'도 옆에 표시해야 함 → 대체당 1탄 글로 연결
6. ⑤ **'고단백'의 기준** — 1일 기준치(55g)의 20% = **100g당 11g / 100ml당 5.5g / 100kcal당 5.5g / 1회 섭취참고량당 11g 중 하나만** 넘으면 '고단백'. 그래서 한 봉지 단백질 g + **단백질 1g당 칼로리**를 직접 계산해서 비교 (예시 제품 2개 계산)
